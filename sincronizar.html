Conectar con la hoja

Guía para que Felipe, Cote y Mateo compartan un solo avance del plan, en vez de que cada uno vea el suyo. Se hace una sola vez por persona, con una hoja de cálculo de Google (una tabla como las de Excel, pero que vive en internet). Esta página no está en el menú principal — se comparte por link directo.

Qué resuelve esto

Hoy, cuando alguien marca una tarea en cualquiera de las páginas del plan, esa marca se guarda solo en su propio teléfono o computador. Es como si cada persona tuviera su propio cuaderno: Felipe anota en el suyo, Cote en el de ella, Mateo en el de él. Nadie ve lo que marcaron los demás, salvo que pregunten.

Conectar una hoja de cálculo de Google como almacén compartido soluciona eso: los tres cuadernos pasan a ser uno solo. Cuando Felipe marca "entregué los accesos", Cote y Mateo lo ven al tiro en su propio celular. Y queda registrado quién marcó cada tarea y cuándo.

📱 Hoy

Cada uno ve lo suyo

Felipe marca una tarea en su celular. Cote y Mateo no se enteran hasta que alguien pregunta "¿ya hiciste eso?". El avance real del equipo nadie lo ve completo.

📊Una sola hoja

Nada se pierde si se corta internet. Esto no reemplaza el guardado de cada dispositivo, lo complementa. Cada teléfono o computador sigue guardando su propia copia al marcar una tarea. Si no hay conexión, el cambio se guarda igual ahí y se envía a la hoja compartida apenas vuelva la señal.

Los 5 pasos para conectar la hoja

Se hacen una sola vez. Los pasos 1 a 3 los hace una sola persona del equipo (da lo mismo quién). Los pasos 4 y 5 son para avisarle a Mateo la dirección web (el link) que resulta, así él la deja fija en las páginas y nadie más tiene que repetir esto.

1 Crea la hoja de cálculo

Abre sheets.new en el navegador del celular o el computador (o entra a Google Sheets y crea una hoja nueva). Ponle un nombre fácil de reconocer, por ejemplo "Pedraza — Avance del plan".

✅ Qué deberías ver: una hoja de cálculo vacía, con el nombre que le pusiste arriba a la izquierda.

2 Abre el editor de código y pega el motor

En el menú de arriba, ve a Extensiones → Apps Script. Se abre una pestaña nueva con un editor de código, con algo ya escrito de ejemplo. Borra todo lo que aparezca ahí y pega completo el código de abajo, tal cual, sin cambiar nada.

/** * Motor de sincronización — Plan Pedraza Ilustración * Pega este código en el editor de Apps Script de la hoja de cálculo * (Extensiones → Apps Script) y publícalo como app web: * Implementar → Nueva implementación → Tipo: Aplicación web * Ejecutar como: Yo · Quién tiene acceso: Cualquier usuario * La URL que entrega esa implementación es el valor que va en * localStorage["pedraza-plan:sync-url"] (o en la constante SYNC_URL del cliente). * * La hoja usa 4 columnas: clave | estado | quien | actualizado * Si la hoja está vacía, el script crea esa fila de encabezados solo. */ var NOMBRE_HOJA = 'Checklist'; // cambia esto si tu pestaña se llama distinto var COLUMNAS = ['clave', 'estado', 'quien', 'actualizado']; // Devuelve la hoja de trabajo, creando el encabezado si hace falta. function obtenerHoja_() { var libro = SpreadsheetApp.getActiveSpreadsheet(); var hoja = libro.getSheetByName(NOMBRE_HOJA) || libro.getSheets()[0]; if (hoja.getLastRow() === 0) { hoja.appendRow(COLUMNAS); } return hoja; } // GET: entrega todos los estados guardados como { ok:true, items:{ "bit:xxx":"1", ... } }. function doGet(e) { var hoja = obtenerHoja_(); var datos = hoja.getDataRange().getValues(); // incluye la fila de encabezado var items = {}; for (var i = 1; i < datos.length; i++) { var clave = datos[i][0]; if (!clave) continue; // fila vacía, se ignora items[String(clave)] = String(datos[i][1]); } return respuestaJson_({ ok: true, items: items }); } // POST: recibe { clave, estado, quien } como JSON en texto plano (para no gatillar // el preflight de CORS) y hace upsert: si la clave ya existe la actualiza, si no // agrega una fila nueva. Usa LockService para que dos personas escribiendo al // mismo tiempo no se pisen. function doPost(e) { var candado = LockService.getScriptLock(); try { candado.waitLock(10000); // hasta 10 segundos esperando el turno para escribir var cuerpo = JSON.parse(e.postData.contents); var clave = String(cuerpo.clave || '').trim(); if (!clave) return respuestaJson_({ ok: false, error: 'falta la clave' }); var estado = cuerpo.estado === '1' ? '1' : '0'; var quien = String(cuerpo.quien || 'alguien del equipo'); var ahora = new Date(); var hoja = obtenerHoja_(); var datos = hoja.getDataRange().getValues(); var filaEncontrada = -1; for (var i = 1; i < datos.length; i++) { if (String(datos[i][0]) === clave) { filaEncontrada = i + 1; break; } // +1: getRange es base 1 } if (filaEncontrada === -1) { hoja.appendRow([clave, estado, quien, ahora]); } else { hoja.getRange(filaEncontrada, 1, 1, 4).setValues([[clave, estado, quien, ahora]]); } return respuestaJson_({ ok: true }); } catch (err) { return respuestaJson_({ ok: false, error: String(err) }); } finally { candado.releaseLock(); } } // Arma la respuesta JSON con el tipo de contenido correcto. function respuestaJson_(objeto) { return ContentService .createTextOutput(JSON.stringify(objeto)) .setMimeType(ContentService.MimeType.JSON); }
✅ Qué deberías ver: el editor con el código pegado, empezando con /** y terminando con la función respuestaJson_.

3 Publica la hoja para que la página pueda leerla

Arriba a la derecha del editor, aprieta el botón Implementar → Nueva implementación. En el tipo, elige Aplicación web. En "Ejecutar como" deja Yo. En "Quién tiene acceso" elige Cualquier usuario. Aprieta Implementar.

La primera vez, Google va a pedir autorización. Aparece una pantalla que dice algo como "esta app no está verificada" — es normal, es tu propio código, nadie más lo ve. Aprieta "Configuración avanzada" y luego "Ir a (nombre del proyecto), sin seguridad" para aceptar. Es seguro: la hoja solo guarda qué tarea se marcó, quién y cuándo — ningún dato sensible ni contraseña.

✅ Qué deberías ver: una ventana con una dirección web larga, que empieza con https://script.google.com/...

4 Copia esa dirección web

Selecciona y copia la dirección web completa que te muestra Google al terminar el paso anterior. Baja hasta la sección "Conectar ahora" más abajo en esta misma página y pégala en el campo de texto.

✅ Qué deberías ver: la dirección pegada en el campo de la sección de abajo, lista para apretar "Conectar".

5 Avísale a Mateo esa dirección

Manda esa misma dirección web a Mateo, por el medio que sea más rápido. Él la deja fija en el código de las 5 páginas del plan, así nadie más en el equipo tiene que repetir estos pasos: apenas abran cualquiera de esas páginas, van a quedar conectados solos.

✅ Qué deberías ver: nada en pantalla — este paso es avisar, no configurar nada acá.

Conectar ahora

Pega aquí la dirección web que te entregó Google en el paso 3 y aprieta "Conectar". La página va a guardarla en este dispositivo y va a probar la conexión al tiro, para confirmar que quedó bien.

Cómo saber que está funcionando

Dos lugares para revisar. El primero, en el celular o computador: abajo a la derecha de cualquier página con checklist aparece una píldora chica que avisa el estado. El segundo, en la hoja de cálculo misma: cada tarea marcada aparece ahí como una fila.

No hay internet o la hoja no respondió. Lo marcado sigue guardado en el dispositivo y se envía solo, apenas vuelva la señal.

Preguntas frecuentes

¿Qué pasa si se corta internet?

Nada se pierde. Lo marcado se sigue guardando en el teléfono o computador al tiro, y se envía a la hoja compartida solo cuando vuelve la conexión.

¿Qué pasa si dos personas marcan algo al mismo tiempo?

La hoja usa un turno interno — atiende un cambio a la vez, como una fila de espera. Dos personas escribiendo junto no se pisan ni pierden ningún cambio.

¿Alguien de afuera puede ver la hoja?

Solo quien tenga la dirección web exacta. No lleva contraseñas ni datos personales, solo qué tarea se marcó, quién y cuándo. Aun así, mejor no publicarla en ningún lugar abierto.

¿Se puede desconectar?

Sí, con el botón "Desconectar" de la sección "Conectar ahora", más arriba. Al desconectar, cada página sigue funcionando exactamente igual, solo que guarda el avance nada más en ese dispositivo.

¿Hay que hacer esto en cada teléfono?

Por ahora sí: cada persona pega la misma dirección web una vez, en su propio dispositivo, en la sección "Conectar ahora". Cuando Mateo la deje fija en el código de las páginas, ya no va a hacer falta — va a quedar conectado solo.
